Bienvenido a mi portafolio profesional. Este proyecto es una aplicación web moderna, interactiva y totalmente responsiva diseñada para mostrar mi experiencia, habilidades y proyectos como ingeniero.

## ✨ Características Principales

-   **🎨 Diseño Moderno y Minimalista**: Interfaz limpia con animaciones suaves impulsadas por **Framer Motion**.
-   **🌗 Modo Oscuro/Claro**: Soporte completo para temas, respetando las preferencias del sistema y del usuario.
-   **🌍 Multi-idioma**: Soporte para Español e Inglés.
-   **⌨️ Terminal Interactiva**: Un minijuego/consola para desarrolladores curiosos.
-   **📱 Totalmente Responsivo**: Adaptado para móviles, tablets y escritorio.

## 🛠️ Tecnologías Utilizadas

-   **Core**: React 19, TypeScript
-   **Build Tool**: Vite
-   **Estilos**: CSS Modules / Vanilla CSS
-   **Animaciones**: Framer Motion
-   **Iconos**: Lucide React
-   **Editor de Código**: Monaco Editor
-   **IA**: (Eliminado)

## 🚀 Instalación y Uso Local

Sigue estos pasos para ejecutar el proyecto en tu máquina local:

1.  **Clonar el repositorio**:
    ```bash
    git clone https://github.com/JaimeLaraC/WebProfesional.git
    cd WebProfesional
    ```

2.  **Instalar dependencias**:
    ```bash
    npm install
    ```

3.  **Iniciar servidor de desarrollo**:
    ```bash
    npm run dev
    ```
    Abre `http://localhost:3000` en tu navegador.

## 📦 Despliegue (GitHub Pages)

Este proyecto está configurado para desplegarse automáticamente en GitHub Pages.

### Pasos para desplegar:

1.  Asegúrate de estar en la rama `render` (o tu rama principal).
2.  Ejecuta el comando de despliegue:
    ```bash
    npm run deploy
    ```
    Este comando construirá el proyecto (`npm run build`) y lo subirá automáticamente a la rama `gh-pages`.
3.  Tu web estará disponible en: `https://JaimeLaraC.github.io/WebProfesional/`
